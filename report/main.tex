\section{Objective}
\label{sec:objective}
The aim of this laboratory activity is to:
\begin{itemize}
  \item Develop a ROS 2 package to run control algorithms on a mobile robot.
  \item Obstacle avoidance and dynamic goal chasing with Dynamic Window Approach.
  \item Test the developed algorithms on the real robots following an AprilTag detected through RGB camera.
\end{itemize}
